# Lunara — vitrine de lingerie

Site estático responsivo com página inicial, categorias, seleção de produtos, guia de compra e privacidade.

## Antes de publicar
- “Lunara” é o nome escolhido para esta versão. Antes de usar comercialmente, verifique disponibilidade de domínio, redes sociais e registro de marca.
- Os cartões de produto ainda não têm links de afiliado. Substitua-os pelos seus links Amazon Associados válidos após verificar as regras do programa.
- Esta versão não oferece cadastro de afiliados nem programa próprio.
- As imagens da área de destaque são arte abstrata feita em CSS, não fotos de produtos. Adicione imagens reais somente se tiver permissão para usá-las e conforme as regras do programa.
- Mantenha preços e disponibilidade fora do site ou sincronizados por fonte autorizada; não invente descontos.
- O aviso de afiliados deve seguir os requisitos atuais da Amazon e deixar a relação comercial clara.
- A página não envia mensagens nem faz prospecção automática.

## Testar
Abra `index.html` no navegador.
Para hospedagem gratuita, pode publicar os arquivos em um repositório GitHub e ativar GitHub Pages.
